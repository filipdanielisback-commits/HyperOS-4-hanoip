# Contributing

Thanks for your interest in HyperOS-4-hanoip.

## Before contributing

- Keep claims evidence-based. Link source code, official documentation, or reproducible test logs.
- Mark uncertain statements as hypotheses or unknowns.
- Do not upload proprietary firmware images, vendor blobs, copyrighted applications, private keys, tokens, or personal data.
- Do not submit untested installation packages as safe or stable.
- Keep changes focused and explain what was changed and how it was verified.

## Issues

When reporting a technical finding, include:
- Exact device model / regional variant (never IMEI or serial number)
- Software build and Android version
- Relevant logs with personal data removed
- Steps to reproduce
- Expected and observed result
- Whether the result is verified, observed, a hypothesis, or unknown

## Pull requests

- Explain the purpose and scope.
- Cite the source of new technical information.
- Identify licensing implications for imported code or assets.
- State what was tested and what was not tested.
- Do not claim a booting or working build without reproducible evidence.
